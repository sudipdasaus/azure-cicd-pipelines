# Azure CI/CD Pipelines

End-to-end Azure infrastructure automation using Azure DevOps pipelines to
orchestrate Terraform, Ansible, and Bash — provisioning and configuring cloud
infrastructure through a single, repeatable delivery path.

---

## Purpose

Reusable, production-oriented CI/CD patterns for Azure infrastructure. The focus
is a "golden path": one pipeline that takes infrastructure from code to a running,
configured environment with security and quality gates built in — the same
approach I used to standardise delivery across multiple teams.
